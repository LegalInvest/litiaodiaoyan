- **起**：01 知识宇宙——知识是可计量的（EduKG / Marble / The Knowledge Cosmos / Paperscape / Open Knowledge Maps / Connected Papers）
- **承**：02–08 方法论主体——五职业五把刀、义乌考古（北苑→后宅→义亭）、六维框架、三级产业链调研、四线研究法、点线面体
- **转**：09–13 猎捕奇点——溯因推理、取数（问题域×解答域）、问题链与问题爆炸扩散数据库、香农信息论、穷尽思维
- **合**：14–20 落地——数据纪律四条铁律、对标（份额从哪抢）、实战案例五则、认知自白、工具化愿景、知识索引、演讲路径

## 核心命题

1. 数据之大，不在于其大，而在于其全。
2. 旁线才是洞见的产地（树形→网状→立体）。
3. 数字与口径必须成对出现；缺失宁可留空也不编造。
4. 在常态里发现反常，在反常里看见机会。
5. 方法可复制，大脑不必复制。
